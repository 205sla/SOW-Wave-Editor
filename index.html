Settings — 테마:
MonsterType 매핑
표시 이름은 편집 화면 드롭다운에 노출. BP 경로는 /Game/01Blueprints/Enemy/ 하위만 입력 — export 시 공통 prefix와 /Script/Engine.BlueprintGeneratedClass'…'가 자동으로 붙습니다. /로 시작하면 그대로 사용.
BehaviorTree 매핑
BT 경로도 /Game/01Blueprints/Enemy/ 하위만 입력 — export 시 공통 prefix와 /Script/AIModule.BehaviorTree'…'가 자동으로 붙습니다. BT 미선택은 export에 "None"으로 출력됩니다.
Route 목록
UE EnemyRoutes DataTable의 행 이름 (FName). 각 MonsterSpawnData가 사용할 이동 경로 식별자. 빈 Route는 export 시 "None"이 되어 UE에서 기본 route fallback이 사용됩니다.
